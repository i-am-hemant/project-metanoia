## Invariant

The window `[left, right]` always contains distinct characters. On seeing a repeat, `left`
jumps *past* the previous occurrence rather than advancing one step at a time — that jump is
what keeps the whole scan linear instead of quadratic.

Space is bounded by the alphabet, not the input: $O(\min(n, |\Sigma|))$.

    last_seen: dict[str, int] = {}

        const unsigned char c = s[right];

## Failure modes

- Forgetting the `last_seen[ch] >= left` guard: a stale index outside the window drags `left`
  backwards and the answer inflates.
- The C++ version assumes ASCII via a fixed 128-slot table; Unicode input needs a hash map.
